# UDS OTA Flow (3-Phase Cross-Reset)

> **相关文档:** [flash分区.md](flash分区.md) — 扇区布局 | [flash操作.md](flash操作.md) — Flash 函数全集 | [OTA-flash补充.md](OTA-flash补充.md) — OTA 跳转参数 & 空闲扇区

## Shared Flash State

- **Sector**: `0x00010000` (56 bytes, `stc_uds_shared_t`)
- **Magic**: `0x55445300` ("UDS\0")
- **Fields**: `magic | phase | target_slot | fw_size | fw_crc | result | pending_sid | reserved[7]`

### Phase Values

| Phase | Value | Who Writes | Meaning |
|-------|-------|------------|---------|
| `UDS_PHASE_IDLE` | 0 | Bootloader (clear) | Normal operation |
| `UDS_PHASE_ENTER_BOOTLOADER` | 1 | APP (0x31 handler) | Request to enter bootloader |
| `UDS_PHASE_PROGRAMMING_DONE` | 2 | Bootloader (FlashDownload) | Firmware download complete |

### pending_sid Values

| pending_sid | Meaning | Who Sets | Who Sends ACK |
|-------------|---------|----------|---------------|
| 0x11 | ECU Reset deferred ACK | Bootloader (0x11 handler) | APP (App_CheckPendingUdsAck) |
| 0x31 | RoutineControl deferred ACK | APP (0x31 handler) | Bootloader (Bootloader_UdsMain) |
| 0 | No pending ACK | Bootloader (UdsShared_Clear) | - |

### Design Rule

> **Whoever receives the UDS command writes to shared Flash and resets WITHOUT sending a CAN response. The next firmware after reboot sends the deferred positive response.**

## Phase 1: APP (Routine Control 0x31 triggers transition)

```
TBOX                          ECU (APP)
 |                              |
 |-- 10 03 (extended session) -->|
 |<-- 50 03 --------------------|
 |                              |
 |-- 27 01 (seed request) ----->|
 |<-- 67 01 [4-byte seed] ------|
 |                              |
 |-- 27 02 [4-byte key] ------->|
 |<-- 67 02 --------------------|  (security unlocked)
 |                              |
 |-- 31 01 xx xx [routine ctrl] ->|
 |                              |
 |   [APP detects SCB->VTOR is APP1/APP2]
 |   Write UDS shared Flash:
 |     phase = UDS_PHASE_ENTER_BOOTLOADER
 |     pending_sid = 0x31 (set by UdsShared_SetPhase)
 |   *resp_len = 0 (NO CAN response!)
 |   NVIC_SystemReset()
 |                              |
 |   ---- ECU RESETS ----       |
```

### Step detail

| Step | Who | Action |
|------|-----|--------|
| 1.1 | TBOX | Send `10 03` (extended diagnostic session) |
| 1.2 | APP | Respond `50 03` (positive) |
| 1.3 | TBOX | Send `27 01` (request seed) |
| 1.4 | APP | Respond `67 01` + 4-byte seed |
| 1.5 | TBOX | Send `27 02` + 4-byte key (CRC8) |
| 1.6 | APP | Respond `67 02` (security unlocked) |
| 1.7 | TBOX | Send `31 01 xx xx` (routine control, RID=...) |
| 1.8 | APP | Detect `SCB->VTOR` is APP, write `phase=ENTER_BOOTLOADER` to shared Flash |
| 1.9 | APP | Set `*resp_len = 0` (NO CAN response), call `NVIC_SystemReset()` |

## Phase 2: Bootloader (Download + 0x34/0x36/0x37 + deferred 31 ACK)

```
                         ECU (Bootloader)
                              |
   Bootloader_UdsMain() starts:
   1. Send deferred 31 ACK (71 01 FF 00) via ISOTP  <-- COMPLETES Phase 1 deferred response
   2. Init FlashDownload (target = UDS_TARGET_FLASH_ADDR = APP2, 0x4C000)
   3. Init UDS
   4. Handle 0x31 in bootloader context:
      Boot_SetRunSlotToAddr(UDS_POST_FLASH_BOOT_ADDR) --> writes APP1 magic to 0x7C000
                              |
   5. Enter main loop:
      CAN poll + ISOTP/UDS + FlashDownload + WDT (500ms)
                              |
 TBOX                          |
 |                              |
 |-- 10 02 (programming session) ->|
 |<-- 50 02 --------------------|
 |                              |
 |-- 27 01 (seed request) ----->|
 |<-- 67 01 [4-byte seed] ------|
 |                              |
 |-- 27 02 [4-byte key] ------->|
 |<-- 67 02 --------------------|  (security unlocked)
 |                              |
 |-- 34 00 44 [addr=0x08004000] [size] ->|   (RequestDownload)
 |   Bootloader maps: addr - 0x08004000 + FW_APP_START_ADDR
 |                   = 0x0004C000 (APP2)
 |   Erase APP2 sectors
 |<-- 74 40 00 -----------------|  (max block size = 0x4000)
 |                              |
 |-- 36 01 [data block 1] ----->|
 |<-- 76 01 --------------------|  (transfer data ACK)
 |                              |
 |-- 36 02 [data block 2] ----->|
 |<-- 76 02 --------------------|
 |   ... (more 0x36 blocks) ... |
 |                              |
 |-- 36 NN [last data block] -->|
 |<-- 76 NN --------------------|
 |                              |
 |-- 37 (request transfer exit) ->|
 |   FlashDownload_Task() does verify
 |<-- 77 -----------------------|  (transfer exit ACK)
 |                              |
 |   In main loop, detect:
 |   FlashDownload_GetState() == FW_UPDATE_COMPLETE
 |   Write UDS shared Flash:
 |     phase = PROGRAMMING_DONE
 |     result = 1 (success)
 |     target_slot = SLOT_APP2
 |   Does NOT reset - keeps running
 |                              |
 |-- 11 01 (ECU Reset) ------->|
 |                              |
 |   [Bootloader detects SCB->VTOR == 0, enters uds_handle_ecu_reset]
 |   MAIN_D(">>> Handle 0x11 (ECU Reset)...")
 |   MAIN_D("  Bootloader context, writing pending_sid=0x11 to flash")
 |   Read UDS shared flash:
 |     magic=0x55445300, phase=PROGRAMMING_DONE, pending_sid=0
 |   Write: pending_sid = 0x11
 |   MAIN_D("  pending_sid=0x11 written to flash at 0x00010000")
 |   *resp_len = 0 (NO CAN response!)
 |   MAIN_D("  Resetting now...")
 |   NVIC_SystemReset()
 |                              |
 |   ---- ECU RESETS ----       |
```

### Step detail

| Step | Who | Action |
|------|-----|--------|
| 2.1 | Bootloader | `Bootloader_UdsMain()` starts, sends deferred `71 01 FF 00` (31 ACK) via ISOTP |
| 2.2 | Bootloader | Init FlashDownload target = APP2 (0x4C000, max 48KB) |
| 2.3 | Bootloader | Init UDS, handle 0x31: call `Boot_SetRunSlotToAddr(UDS_POST_FLASH_BOOT_ADDR)` → write APP1 magic to 0x7C000 |
| 2.4 | TBOX | Send `10 02` (programming session) |
| 2.5 | Bootloader | Respond `50 02` |
| 2.6 | TBOX | Send `27 01` → `27 02` (security unlock) |
| 2.7 | TBOX | Send `34 00 44 [addr=0x08004000] [size]` (RequestDownload) |
| 2.8 | Bootloader | Map `0x08004000` → `0x0004C000` (APP2), erase sectors, respond `74 40 00` |
| 2.9 | TBOX | Send `36 01 [data]` … `36 NN` (TransferData blocks) |
| 2.10 | Bootloader | Respond `76 01` … `76 NN` (block ACK) |
| 2.11 | TBOX | Send `37` (RequestTransferExit) |
| 2.12 | Bootloader | Respond `77`, trigger verify |
| 2.13 | Bootloader | Main loop detects `FW_UPDATE_COMPLETE`, writes shared Flash: `phase=PROGRAMMING_DONE, result=1, target_slot=SLOT_APP2` |
| 2.14 | TBOX | Send `11 01` (ECU Reset) |
| 2.15 | Bootloader | `uds_handle_ecu_reset`: `MAIN_D` prints, writes `pending_sid=0x11`, `*resp_len=0`, `NVIC_SystemReset()` |

## Phase 3: Bootloader → APP1 → deferred 51 01 ACK

```
                         ECU (Bootloader restarts)
                              |
   Boot_StartupSequence():
   1. Check shared RAM debug flag
   2. Check UDS Shared State:
      phase=PROGRAMMING_DONE (NOT ENTER_BOOTLOADER => skip Bootloader_UdsMain)
   3. CheckAndClearAppState()
   4. GetWdtResetType() -- NOT a WDT reset
   5. GetCurrentSlot() -- reads APP_RUN_SLOT_ADDR (0x7C000)
      → sees SLOT_A_MAGIC (0x5A5A5A5A) → eCurrentSlot = APP1
   6. InitAppInfo for APP1 and APP2
   7. ValidateSlotFlag, UpdateAppState, HandleWatchdogReset
   8. SelectTargetSlot → APP1 (current slot, healthy)
   9. UpdateSlotFlagToFlash → write APP1 magic to 0x7C000
  10. Bootloader_JumpToApp(APP1_START_ADDR = 0x1A000)
      → set MSP, VTOR=0x1A000, branch to reset vector
                              |
                         ECU (APP1 starts)
                              |
   APP1 main():
   1. SCB->VTOR = APP1_START_ADDR (0x1A000)
   2. __enable_irq()
   3. Hardware_Init()
   4. MAIN_D("APP1 Running...")
   5. App_CheckPendingUdsAck():
      - Read UDS shared flash (0x10000)
      - magic = 0x55445300 ✓
      - pending_sid = 0x11 → YES!
      - MAIN_D("Sending pending 11 01 ACK (51 01)")
      - Build CAN frame:
        CAN ID = 0x18DAF103 (phys response)
        DLC = 8
        Data = {0x04, 0x51, 0x01, 0x00, 0x00, 0x00, 0x00, 0x00}
              ^^^^  ^^^^^^
              PCI   UDS positive response to 0x11
        (ISOTP single frame, PCI=0x04 = 4 bytes payload)
      - CanIf_Send(&stcMsg) --> raw CAN send (ISOTP NOT initialized yet)
      - UdsShared_Clear() → erase shared sector
                              |
 TBOX                          |
 |<-- [ISOTP SF] 51 01 --------|  (deferred ECU reset ACK!)
 |                              |
 |   [OTA flow complete]        |
```

### Step detail

| Step | Who | Action |
|------|-----|--------|
| 3.1 | Bootloader | Restart after 0x11 reset, `Boot_StartupSequence()` checks UDS shared: phase is PROGRAMMING_DONE (not ENTER_BOOTLOADER), skips UDS mode |
| 3.2 | Bootloader | Read `APP_RUN_SLOT_ADDR` (0x7C000) → sees APP1 magic → select APP1 as target |
| 3.3 | Bootloader | `Bootloader_JumpToApp(0x1A000)`: set MSP from APP1 vector table, set VTOR=0x1A000, branch to reset vector |
| 3.4 | APP1 | `Hardware_Init()`, then call `App_CheckPendingUdsAck()` |
| 3.5 | APP1 | Read shared Flash: `pending_sid == 0x11` → send deferred `51 01` via raw CAN (manual ISOTP SF PCI byte `0x04`) |
| 3.6 | APP1 | `UdsShared_Clear()` → erase shared sector, enter normal main loop |

## Context Detection

```c
// In UDS handlers (uds_diagnostic.c):
if (SCB->VTOR == APP1_START_ADDR || SCB->VTOR == APP2_START_ADDR) {
    // Running in APP context
} else {
    // Running in Bootloader context (SCB->VTOR == 0 for bootloader)
}
```

## Address Mapping

```
TBOX address:  0x08004000
MAP_TBOX_ADDR_TO_FLASH(0x08004000)
  = 0x08004000 - 0x08004000 + 0x0004C000
  = 0x0004C000  (APP2_START_ADDR)
```

## Key Macros

| Macro | Value | Purpose |
|-------|-------|---------|
| `UDS_TARGET_FLASH_ADDR` | `0x4C000` (APP2) | Flash download target |
| `UDS_POST_FLASH_BOOT_ADDR` | `0x1A000` (APP1) | Forced boot slot after flash (macro, currently hardcoded) |
| `FW_APP_START_ADDR` | `0x0004C000` (APP2) | Base for TBOX address mapping |
| `UDS_SHARED_SECTOR_BASE` | `0x00010000` | Shared Flash state sector |
| `UDS_SHARED_MAGIC` | `0x55445300` | "UDS\0" validation magic |
| `APP_RUN_SLOT_ADDR` | `0x0007C000` | Active slot magic storage |

> 各宏对应 Flash 操作的详细函数、扇区、保护状态见 [flash操作.md](flash操作.md)

## 0x11 Handler Implementation Details

The 0x11 handler (`uds_handle_ecu_reset`) in `uds_diagnostic.c` uses `MAIN_D()` for all debug prints (instead of `UDS_I()`) so output is always visible regardless of `UDS_DEBUG`:

```c
static void uds_handle_ecu_reset(uint8_t* data, uint8_t len, uint8_t* resp, uint8_t* resp_len)
{
    MAIN_D(">>> Handle 0x11 (ECU Reset), VTOR=0x%08X\r\n", (unsigned int)SCB->VTOR);
    // ...
    if (SCB->VTOR == 0) {
        MAIN_D("  ECU Reset: Bootloader context, writing pending_sid=0x11 to flash\r\n");
        stc_uds_shared_t state;
        UdsShared_Read(&state);
        MAIN_D("  Shared state: magic=0x%08X, phase=%d, pending_sid=0x%02X\r\n", ...);
        if (state.magic == UDS_SHARED_MAGIC) {
            state.pending_sid = 0x11;
            UdsShared_Write(&state);
            MAIN_D("  pending_sid=0x11 written to flash at 0x%08X\r\n", ...);
        }
        *resp_len = 0;
        MAIN_D("  Resetting now...\r\n");
        NVIC_SystemReset();
        while(1);
    } else {
        MAIN_D("  ECU Reset: APP context, sending normal response\r\n");
        resp[0] = reset_type;
        *resp_len = 1;
    }
}
```

## Deferred 51 01 ACK Implementation Details

`App_CheckPendingUdsAck()` sends the deferred ACK using **raw CAN** (not ISOTP) because ISOTP is not yet initialized when this function runs in APP startup:

```c
if (state.pending_sid == 0x11) {
    MAIN_D("  Sending pending 11 01 ACK (51 01)\r\n");
    /* ISOTP single frame: PCI=0x04 (4 bytes payload) + 51 01 00 00, DLC=8 */
    CanMsg_t stcMsg;
    uint8_t au8Data[8] = {0x04, 0x51, 0x01, 0x00, 0x00, 0x00, 0x00, 0x00};
    // ... fill stcMsg ...
    CanIf_Send(&stcMsg);
}
```

## Post-OTA Boot Address Control

After OTA flash completes, the bootloader always boots APP1. This is controlled by:

```c
// Bootloader_App.h, line 31:
#define UDS_POST_FLASH_BOOT_ADDR         APP1_START_ADDR   // = 0x1A000

// uds_diagnostic.c, 0x31 handler (bootloader context):
Boot_SetRunSlotToAddr(UDS_POST_FLASH_BOOT_ADDR);  // writes APP1 magic to 0x7C000
```

To change the post-OTA boot target (e.g., to APP2), change `UDS_POST_FLASH_BOOT_ADDR` to `APP2_START_ADDR` in all three copies of `Bootloader_App.h` (boot/, app1/, app2/).

Note: this is a development hardcode. The plan is to make it dynamic based on which slot received the new firmware.
