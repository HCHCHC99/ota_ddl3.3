# UDS OTA Flow (3-Phase Cross-Reset)

## Shared Flash State

- **Sector**: `0x00010000` (56 bytes, `stc_uds_shared_t`)
- **Magic**: `0x55445300` ("UDS\0")
- **Fields**: `magic | phase | target_slot | fw_size | fw_crc | result | pending_sid | reserved[7]`

### Phase Values

| Phase | Value | Who Writes | Meaning |
|-------|-------|------------|---------|
| `UDS_PHASE_IDLE` | 0 | Bootloader (clear) | Normal operation |
| `UDS_PHASE_ENTER_BOOTLOADER` | 1 | APP (0x31 handler) | Request to enter bootloader |
| `UDS_PHASE_PROGRAMMING_DONE` | 2 | Bootloader (FlashDownload) | Firmware download complete |

### Design Rule

> **Whoever receives the UDS command writes to shared Flash and resets WITHOUT sending a CAN response. The next firmware after reboot sends the deferred positive response.**

## Phase 1: APP (Routine Control 0x31 triggers transition)

```
TBOX                          ECU (APP)
 |                              |
 |-- 10 03 (extended session) -->|
 |<-- 50 03 --------------------|
 |                              |
 |-- 27 01 (seed request) ----->|
 |<-- 67 01 [4-byte seed] ------|
 |                              |
 |-- 27 02 [4-byte key] ------->|
 |<-- 67 02 --------------------|  (security unlocked)
 |                              |
 |-- 31 01 xx xx [routine ctrl] ->|
 |                              |
 |   [APP detects SCB->VTOR is APP1/APP2]
 |   Write UDS shared Flash:
 |     phase = UDS_PHASE_ENTER_BOOTLOADER
 |   *resp_len = 0 (NO CAN response!)
 |   NVIC_SystemReset()
 |                              |
 |   ---- ECU RESETS ----       |
```

### Step detail

| Step | Who | Action |
|------|-----|--------|
| 1.1 | TBOX | Send `10 03` (extended diagnostic session) |
| 1.2 | APP | Respond `50 03` (positive) |
| 1.3 | TBOX | Send `27 01` (request seed) |
| 1.4 | APP | Respond `67 01` + 4-byte seed |
| 1.5 | TBOX | Send `27 02` + 4-byte key (CRC8) |
| 1.6 | APP | Respond `67 02` (security unlocked) |
| 1.7 | TBOX | Send `31 01 xx xx` (routine control, RID=...) |
| 1.8 | APP | Detect `SCB->VTOR` is APP, write `phase=ENTER_BOOTLOADER` to shared Flash |
| 1.9 | APP | Set `*resp_len = 0` (NO CAN response), call `NVIC_SystemReset()` |

## Phase 2: Bootloader (Download + 0x34/0x36/0x37 + deferred 0x71 ACK)

```
                         ECU (Bootloader)
                              |
   Bootloader_UdsMain() starts:
   1. Init ISOTP, CAN filters
   2. Init FlashDownload (target = UDS_TARGET_FLASH_ADDR = APP2)
   3. Init UDS
                              |
   4. Check UDS shared Flash:
      phase == ENTER_BOOTLOADER?
        YES: clear phase to IDLE
              send deferred 0x71 ACK via UDS
                              |
   5. Enter main loop:
      CAN poll + ISOTP/UDS + FlashDownload + WDT
                              |
 TBOX                          |
 |                              |
 |-- 10 02 (programming session) ->|
 |<-- 50 02 --------------------|
 |                              |
 |-- 27 01 (seed request) ----->|
 |<-- 67 01 [4-byte seed] ------|
 |                              |
 |-- 27 02 [4-byte key] ------->|
 |<-- 67 02 --------------------|  (security unlocked)
 |                              |
 |-- 34 00 44 [addr=0x80004000] [size] ->|   (RequestDownload)
 |   Bootloader maps: addr - 0x80004000 + FW_APP_START_ADDR
 |                   = 0x0004C000 (APP2)
 |   Erase APP2 sectors
 |<-- 74 40 00 -----------------|  (max block size = 0x4000)
 |                              |
 |-- 36 01 [data block 1] ----->|
 |<-- 76 01 --------------------|  (transfer data ACK)
 |                              |
 |-- 36 02 [data block 2] ----->|
 |<-- 76 02 --------------------|
 |   ... (more 0x36 blocks) ... |
 |                              |
 |-- 36 NN [last data block] -->|
 |<-- 76 NN --------------------|
 |                              |
 |-- 37 (request transfer exit) ->|
 |   FlashDownload_Task() does verify
 |<-- 77 -----------------------|  (transfer exit ACK)
 |                              |
 |   In main loop, detect:
 |   FlashDownload_GetState() == FW_UPDATE_COMPLETE
 |   Write UDS shared Flash:
 |     phase = PROGRAMMING_DONE
 |     result = 1 (success)
 |     target_slot = SLOT_APP2
 |                              |
```

### Step detail

| Step | Who | Action |
|------|-----|--------|
| 2.1 | Bootloader | `Bootloader_UdsMain()` starts, inits ISOTP/CAN/FW/UDS |
| 2.2 | Bootloader | Read shared Flash: if `phase==ENTER_BOOTLOADER`, clear to IDLE and send deferred `71` (positive response to 0x31) |
| 2.3 | TBOX | Send `10 02` (programming session) |
| 2.4 | Bootloader | Respond `50 02` |
| 2.5 | TBOX | Send `27 01` (seed request) |
| 2.6 | Bootloader | Respond `67 01` + seed |
| 2.7 | TBOX | Send `27 02` + key |
| 2.8 | Bootloader | Respond `67 02` (unlock) |
| 2.9 | TBOX | Send `34 00 44 [4-byte addr=0x08004000] [4-byte size]` (RequestDownload) |
| 2.10 | Bootloader | Map `0x08004000` → `0x0004C000` (APP2), erase sectors |
| 2.11 | Bootloader | Respond `74 40 00` (max block = 0x4000 = 16KB) |
| 2.12 | TBOX | Send `36 01 [data]` (TransferData block 1…N) |
| 2.13 | Bootloader | Respond `76 01` … `76 NN` (block ACK) |
| 2.14 | TBOX | Send `37` (RequestTransferExit) |
| 2.15 | Bootloader | Respond `77`, trigger verify |
| 2.16 | Bootloader | Main loop detects `FW_UPDATE_COMPLETE`, writes shared Flash: `phase=PROGRAMMING_DONE, result=1, target_slot=SLOT_APP2` |

## Phase 3: APP reboot + ECU Reset 0x11 → deferred 0x51 ACK

```
                         ECU (APP, after reboot)
                              |
   Boot_StartupSequence():
   Check UDS shared Flash:
     pending_sid == 0x11?
       YES: send deferred 51 (positive response to 0x11)
            clear pending_sid to 0
     phase == PROGRAMMING_DONE?
       YES: read fw info, clear phase to IDLE
                              |
 TBOX                          |
 |                              |
 |-- 10 01 (default session) ->|
 |<-- 50 01 --------------------|
 |                              |
 |-- 11 01 (ECU reset) ------->|
 |                              |
 |   [Bootloader detects SCB->VTOR == 0]
 |   Write UDS shared Flash:
 |     pending_sid = 0x11
 |   *resp_len = 0 (NO CAN response!)
 |   NVIC_SystemReset()
 |                              |
 |   ---- ECU RESETS ----       |
 |                              |
 |   Bootloader starts:
 |   VTOR == APP_RUN_SLOT magic (= SLOT_APP1)
 |   Run APP1 (the newly flashed APP at 0x1A000)  |
 |                              |
 |   APP1 starts:
 |   App_CheckPendingUdsAck():
 |     Read shared Flash:
 |       pending_sid == 0x11?
 |         YES: send deferred 51 01 (ECU reset ACK)
 |              clear pending_sid to 0
 |       phase == PROGRAMMING_DONE?
 |         YES: read fw_size/fw_crc/result
 |              clear phase to IDLE
 |                              |
 |<-- 51 01 --------------------|  (deferred ECU reset ACK)
 |                              |
```

### Step detail

| Step | Who | Action |
|------|-----|--------|
| 3.1 | Bootloader | Start, check `APP_RUN_SLOT` → points to APP1 (set during Phase 2 via `Boot_SetRunSlotToAddr`) |
| 3.2 | Bootloader | Jump to APP1 (at `0x1A000`) |
| 3.3 | APP1 | `Boot_StartupSequence()` → `App_CheckPendingUdsAck()` |
| 3.4 | APP1 | Read shared Flash: check `pending_sid`, `phase`, send any deferred ACKs |
| 3.5 | APP1 | Clear shared Flash state, run normal main loop |
| 3.6 | TBOX | Send `10 01` (default session) |
| 3.7 | APP1 | Respond `50 01` |
| 3.8 | TBOX | Send `11 01` (ECU reset - hardware) |
| 3.9 | (Bootloader) | Write `pending_sid = 0x11` to shared Flash |
| 3.10 | (Bootloader) | Set `*resp_len = 0` (NO CAN response), `NVIC_SystemReset()` |
| 3.11 | Bootloader | Restarts, check `APP_RUN_SLOT`, jump to APP1 |
| 3.12 | APP1 | `App_CheckPendingUdsAck()` sends deferred `51 01` (0x11 positive response) |

## Context Detection

```c
// In UDS handlers (uds_diagnostic.c):
if (SCB->VTOR == APP1_START_ADDR || SCB->VTOR == APP2_START_ADDR) {
    // Running in APP context
} else {
    // Running in Bootloader context (SCB->VTOR == 0 for bootloader)
}
```

## Address Mapping

```
TBOX address:  0x08004000
MAP_TBOX_ADDR_TO_FLASH(0x08004000)
  = 0x08004000 - 0x08004000 + 0x0004C000
  = 0x0004C000  (APP2_START_ADDR)
```

## Key Macros

| Macro | Value | Purpose |
|-------|-------|---------|
| `UDS_TARGET_FLASH_ADDR` | `0x4C000` (APP2) | Flash download target |
| `UDS_POST_FLASH_BOOT_ADDR` | `0x1A000` (APP1) | Forced boot slot after flash |
| `FW_APP_START_ADDR` | `0x0004C000` (APP2) | Base for TBOX address mapping |
| `UDS_SHARED_SECTOR_BASE` | `0x00010000` | Shared Flash state sector |
| `UDS_SHARED_MAGIC` | `0x55445300` | "UDS\0" validation magic |
